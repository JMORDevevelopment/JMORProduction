PROJECT NAME:
JMOR Production — CodeIgniter to Laravel 13 Migration

------------------------------------------------------------
SHORT DESCRIPTION (for LinkedIn project card):
------------------------------------------------------------
Migrated a full-scale production IT services website from legacy CodeIgniter to Laravel 13 with Livewire 4, Filament 5, and modern PHP 8.5 practices.

------------------------------------------------------------
DETAILED DESCRIPTION (for LinkedIn "About" section):
------------------------------------------------------------
Led the complete migration of JMOR Production (jmor.com) — a live IT services and solutions company website — from a legacy CodeIgniter (CI3) codebase to a modern Laravel 13 application. The project involved porting 60+ views, 30+ controllers, and 40+ database tables while maintaining identical UI/UX and business logic.

Key contributions:
• Ported the entire user-facing frontend (homepage, auth, packages, checkout, dashboard, content pages, blog, news, events, case studies, media relations, services, radio shows, testimonials, contact forms, and more)
• Implemented secure authentication (login, signup, forgot password) with session-based middleware
• Built the full checkout and payment flow (cart, checkout, payment processing, order confirmation, invoicing)
• Developed the user dashboard (orders, invoice, settings, gift cards, testimonials)
• Created 40+ Laravel controllers following proper MVC architecture with Form Request validation
• Built Blade views using @extends, @section, @push/@prepend/@stack directives for clean asset management
• Implemented server-side validation using Form Requests with custom error messages
• Added CAPTCHA-based spam protection on all public forms
• Migrated 40+ database tables preserving exact CI schema structure
• Created Laravel migrations for test database setup
• Implemented email notifications for contact forms, media inquiries, and request information forms
• Fixed navigation/footer route links and resolved CMS page routing with catch-all routes
• Ported all content pages (services, radio shows, recommended, random acts of kindness, etc.)
• Implemented site-wide search across blogs and CMS pages
• Used Pest PHP for testing with 29+ test cases
• Applied Laravel Pint for consistent code formatting
